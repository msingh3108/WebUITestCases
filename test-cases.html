🐞 Recent Bug Findings
Bug ID Component Summary Status
WUIF-84 Forms - Date Field Validation Date field with "Disable Past Dates" becomes invalid after a previously submitted form is reopened later
  • Add a Date field to a form and enable the "Disable Past Dates" toggle
  • Submit the form with today's date, then reopen/review it on a later day
  • Actual: the previously submitted date is revalidated against the current day and is flagged as invalid because it is now in the past
  • Expected: "Disable Past Dates" should only prevent selecting a past date during entry/edit, not invalidate an already-submitted value during later review (e.g. Manager Review)
  • Customer workaround: uses two separate fields / alternate form design to avoid the validation problem in later workflow stages
 Not Automated
WUIF-103 Page Builder - Auto Query Tile Auto Query tile count backed by a Workflow Queue caps at 50 regardless of actual queue size
  • Configure an Auto Query control with a Workflow Queue data source and enable the count display for tile view
  • Queues with 49 items show the correct count; queues with 52 items display as 50
  • Root cause unknown: could be an OnBase/Unity API page-size limitation or a Canvas-side pagination/count handling issue (auto-query-pc store / Canvas.ApiServerClient)
  • Misleading tile count risks users missing or mismanaging work items
  • Acceptance: root cause documented; tile shows exact count or a "50+" (i18n-friendly) indicator at the API cap; no regression on Auto Query tiles using other data sources
 Not Automated
